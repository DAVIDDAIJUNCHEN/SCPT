# 职业教育教学要点（编写参考）

## 课型与教法适配

| 课型 | 适配教法 | 实践占比 |
|---|---|---|
| 理实一体 | 任务驱动、演示-模仿 | 40-60% |
| 纯理论 | 案例教学、问题链 | 0 |
| 实训 | 项目式、工单制 | ≥70% |
| 混合式 | 翻转+线下内化 | 线上 30% 左右 |

## 教学目标动词参考（可观测层级）

- **知识**：说出、列举、解释、比较、归纳
- **能力（操作）**：安装、配置、编写、调试、排查、部署、优化
- **能力（分析设计）**：分析、设计、评估、选型、改造
- **素养**：遵守规范、主动核查、协作分工、复盘改进

禁用裸动词：了解、掌握、熟悉、理解（无法检验）。

## 素养目标融入方式

- **自然融入**：任务本身蕴含（如实操必须按安全规程 → 职业规范）
- **情境融入**：真实岗位案例（如某企业生产事故复盘 → 责任意识）
- **禁止**：结尾硬贴一段思政口号

## 实操环节设计要素

1. 任务工单（任务描述、交付物、验收标准）
2. 分组策略（2-4 人/组，角色分工：操作/记录/检查轮换）
3. 差异化：基础任务 + 进阶任务（学有余力者）
4. 安全提示（涉电/涉网/涉数据操作的规范红线）

## 常见扣分点（教案评审）

- 目标不可观测 / 无法检验
- 环节时长与学时不符
- 有目标但无对应活动（目标悬空）
- 有活动但无设计意图（为活动而活动）
- 重难点无定位依据
- 高职课无岗位/职业场景衔接

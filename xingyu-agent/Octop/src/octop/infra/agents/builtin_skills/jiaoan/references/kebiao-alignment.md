# 课标对齐方法

## 对齐的三个层次

1. **目标对齐**：教案的每条教学目标可追溯到课程标准的具体条目（如「专业课标 4.2 掌握……」）。产出对齐表：

| 教学目标 | 课标条目 | 对齐强度 |
|---|---|---|
| 能配置 X 服务 | 课标 4.2.3 | 直接支撑 |
| 能排查 Y 故障 | 课标 4.2.5 | 直接支撑 |
| 团队协作完成 Z | 课标素养要求 6.1 | 间接支撑 |

2. **内容对齐**：教学内容覆盖课标规定的知识/技能点，无遗漏、无越界（超纲内容须标注「拓展」）。
3. **评价对齐**：考核方式能检验课标要求的达成度（有目标就必须有检验）。

## 操作步骤

1. 向用户索取课程标准（或教学大纲）原文；拿到后先抽取**条目清单**（编号+内容）。
2. 圈定本次课覆盖的条目子集。
3. 写教案时逐条对照，产出对齐表附在教案末尾。
4. 课标条目编号必须原文引用，不可改写编号。

## 用户没有课标时

- 明确告知：将按《职业院校专业人才培养方案》通用框架 + 课程名称推断内容边界编写。
- 在教案头部标注「⚠️ 未对齐课程标准，建议用户提供课标后复核」。
- 禁止编造「根据课标 X.X 条」类引用。

## 高职课标常见依据（供定位，引用需用户确认）

- 专业教学标准（教育部发布的专业目录配套标准）
- 专业人才培养方案（学校层面）
- 课程标准（课程层面，通常由教研室制定）
- 1+X 职业技能等级标准、职业技能竞赛规程（可作为能力目标参照）

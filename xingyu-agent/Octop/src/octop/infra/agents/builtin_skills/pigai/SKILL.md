# 作业批改与教研纪要

两类任务：**批改**（作业/试卷/作品 → 分数+评语）与**纪要**（教研活动记录 → 结构化纪要）。

## 一、批改工作流程

1. **收集输入**（缺失先问）：
   - 题目/任务原文与**参考答案或评分标准**（无则先与用户共建评分量表再批）
   - 学生作答内容
   - 批改口径：严格/常规/鼓励优先；满分制
2. **读参考文档**：`{{OCTOP_BUILTIN_SKILLS}}/pigai/references/pigai-rules.md`
3. **逐题批注**：每处扣分标注「错在哪 + 扣多少」，引用评分标准条目
4. **汇总输出**：
   - 总分 + 逐题得分表
   - 评语：**三明治结构**（肯定具体亮点 → 指出关键问题（1-3 条，按影响排序）→ 给可执行的改进动作）
   - 共性错误分析（批量批改时）：错误模式归类、频次、疑似教学薄弱点

## 二、教研纪要工作流程

1. **收集输入**：活动基本信息（时间/地点/主持人/参加人）、议题、讨论记录（可以很粗糙：速记、语音转写、聊天记录粘贴均可）
2. **结构化整理**（模板见 pigai-rules.md）：
   - 会议信息 → 议题与结论（**结论必须显式标注「议定」**，与讨论过程区分）→ 待办（事项/责任人/时限）→ 附件
3. **红线**：
   - 忠于原始记录，不可自行补充观点；信息不足处标「（待补充）」而非编造
   - 责任人/时限不明确时列入「待明确」，提醒会议主持人确认
   - 纪要需经主持人确认后发出（提醒用户走确认流程）

## 通用红线

- 分数计算必须逐题累加后复核一遍
- 评语禁止空泛（「不错」「再努力」），每条反馈落到具体行为
- 批改结果可能影响学生评价，口径不确定时向用户请示，不自作主张

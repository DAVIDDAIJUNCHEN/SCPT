# 批改规范与教研纪要模板

## 一、批改规范

### 评分量表（无参考答案时先与用户共建）

| 维度 | 权重 | 满分表现 | 常见失分 |
|---|---|---|---|
| 正确性 | 50-60% | 结论正确、过程完整 | 结论对过程错；概念混淆 |
| 完整性 | 20% | 覆盖任务全部要求 | 漏问、漏步骤 |
| 规范性 | 10-20% | 术语/格式/单位规范 | 口语化表达、无单位 |
| 独立思考 | 0-20% | 有合理的方法选择/反思 | 照抄模板不贴合情境 |

### 逐题批注格式

```
第 3 题（5 分）得 3 分
- ✓ 正确写出配置命令（2/2）
- ✗ 缺少重启服务步骤（-1，评分标准②）
- △ 单位写错：Mb→Mbps（-1，规范性）
```

### 评语三明治模板

1. **肯定（具体）**：「第 4 题故障排查思路清晰，先分层后定位，是标准工程做法。」
2. **问题（1-3 条，按影响排序）**：「主要失分在 XX 概念混淆（第 1、7 题），导致 6 分连带丢失。」
3. **改进动作（可执行）**：「复习教材第 X 章 X.X 节，重做第 1、7 题；下次作业先列要点再动笔。」

### 共性错误分析（批量批改）

| 错误模式 | 频次 | 涉及题号 | 疑似教学薄弱点 | 建议补救 |
|---|---|---|---|---|
| 概念 A/B 混淆 | 12/45 | 1,7 | 概念对比未强调 | 下次课加对比表+辨析练习 |

### 听评课记录模板（附加）

- 授课教师/课程/班级/时间
- 课堂观察：目标达成 / 环节实施 / 学生参与 / 亮点 / 商榷处
- 评议意见（议课不评人，先自评后互评）

### 集体备课记录模板（附加）

- 主备人/课题；统一内容（目标/重难点/作业）；个性化空间（分层/专业差异）；分歧与处理

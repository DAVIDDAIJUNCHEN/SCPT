# 双向细目表方法

## 是什么

试卷的「合同」：知识点（纵轴）× 题型与认知层次（横轴）× 分值 的矩阵，确保考核范围、难度、分值分布符合考试目的，先于命题产出。

## 模板

| 知识点 | 认知层次 | 选择 | 判断 | 填空 | 简答 | 综合 | 小计(分) |
|---|---|---|---|---|---|---|---|
| 知识点A（章X） | 识记 | 3题/6分 | 2题/2分 | 1题/2分 | — | — | 10 |
| 知识点B（章X） | 理解 | 4题/8分 | 2题/2分 | 1题/2分 | 1题/5分 | — | 17 |
| 知识点C（章Y） | 应用 | 3题/6分 | — | 1题/2分 | 1题/5分 | 1题/10分 | 23 |
| … | … | | | | | | |
| **合计** | | 40 | 10 | 10 | 20 | 20 | **100** |

## 认知层次（简化布鲁姆）

- **识记**：再认再现（定义、分类、命令名）
- **理解**：解释、比较、举例
- **应用**：在给定情境中执行（配置、计算、排查）
- **分析/综合**：拆解问题、设计方案、评估取舍

## 编制步骤

1. 从课标/教材/用户给的范围抽知识点清单（按章节分组，标注重要性：核心/次要）
2. 按考试性质分配分值权重（期末卷：核心知识点占 60-70%）
3. 填格子：每个知识点分配题型与分值；先保证核心知识点覆盖，再铺次要
4. 行列双自查：行小计 = 知识点权重；列小计 = 题型分值结构
5. 难度列可另加一列标注易/中/难，或用 (E/M/D) 后缀

## 交用户确认的要点

- 覆盖范围是否齐全（有无漏章/超纲）
- 分值权重是否符合教学重心
- 难度分布是否符合考试性质（测验偏易、期末均衡、竞赛模拟偏难）

## 命题后核对

命题完成后反向核对：每道题回填到细目表格子，若某格子空缺或超填，补题/删题。核对表附在答案文档末尾供教研检查。

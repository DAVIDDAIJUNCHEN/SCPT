# 试卷生成

面向职业院校课程考核场景。**先出双向细目表，经用户确认后再命题——细目表是试卷的合同，防止内容跑偏。**

## 工作流程

1. **收集输入**（缺失先问）：
   - 课程名称、考核范围（章节/知识点清单）
   - 考试性质：期中/期末/单元测验/随堂练习/技能认证模拟
   - 题型与分值要求（用户无要求时给默认方案）
   - 考试时长、总分、难度预期（如易:中:难 = 3:5:2）
   - 参考资料：教材/课件/课标（有则对齐，无则说明）
2. **读参考文档**：
   - 命题规范与题型模板：`{{OCTOP_BUILTIN_SKILLS}}/shijuan/references/mingti-rules.md`
   - 双向细目表方法：`{{OCTOP_BUILTIN_SKILLS}}/shijuan/references/ximu-table.md`
3. **产出双向细目表**（知识点 × 题型 × 难度 × 分值矩阵）交用户确认。
4. **按细目表命题**，输出完整试卷：
   - 卷头（课程、考试时间、总分、闭卷/开卷、适用班级）
   - 大题题头含「得分栏」表格
   - 客观题答案分布均衡（选择题正确选项 A/B/C/D 大致均匀，避免连续同选项超 3 个）
5. **产出参考答案与评分标准**（单独成文）：
   - 客观题给答案表
   - 主观题给「要点 + 分值拆分」（按点给分，可操作）
   - 案例分析/实操题给评分量表（维度 × 等级）

## 质量红线

- 分值总和必须等于总分，逐大题自查
- 题目覆盖细目表全部格子，无遗漏无超纲
- 题干无歧义、无暗示答案；选择项干扰项有效（同类别、同长度量级）
- 计算题数据可算（结果整洁）；操作性题目必须给可书面表达的任务
- 答案与试卷分开输出，防止泄题

# 15 种法定文种写作要点

依据《党政机关公文处理工作条例》（中办发〔2012〕14 号）第八条，法定公文共 15 种。本文给出每种文种的适用范围、行文规则、格式要点和常见错误，供起草时选用文种、组织结构和套用版式。

选择文种的根本依据是**行文方向**（上行/下行/平行）和**行文目的**（商洽/请批/周知/执行）。拿不准时先核对下表，不要凭语感选文种。

## 文种速查表

| 文种 | 行文方向 | 核心用途 | 生成器格式 |
|---|---|---|---|
| 决议 | 下行 | 会议讨论通过的重大决策事项 | `--format formal` |
| 决定 | 下行 | 重要事项作出安排、奖惩 | `--format formal` |
| 命令（令） | 下行 | 发布法规、强制性措施、嘉奖 | `--format command` |
| 公报 | 下行（公布） | 公开发布重大决定或重大事项 | `--format formal` |
| 公告 | 下行（公布） | 向国内外宣布重要或法定事项 | `--format formal` |
| 通告 | 下行（公布） | 在一定范围内公布应遵守或周知事项 | `--format formal` |
| 意见 | 上行/下行/平行均可 | 对重要问题提出见解和处理办法 | `--format formal` |
| 通知 | 下行为主 | 发布、转发、批转、周知、执行 | `--format formal` |
| 通报 | 下行 | 表彰先进、批评错误、传达精神 | `--format formal` |
| 报告 | 上行 | 汇报工作、反映情况、回复询问 | `--format formal` |
| 请示 | 上行 | 向上级请求指示、批准 | `--format formal`（上行文） |
| 批复 | 下行 | 答复下级请示事项 | `--format formal` |
| 议案 | 上行（政府→人大） | 政府向同级人大提请审议事项 | `--format formal` |
| 函数（信函式） | 平行 | 不相隶属机关之间商洽、询问、答复 | `--format letter` |
| 纪要 | 会议 | 记载传达会议主要情况和议定事项 | `--format minutes` |

## 各文种详解

### 1. 决议
- **适用**：会议讨论通过的重大决策事项，如党代会、党委全会决议。
- **要点**：标题常为「关于××的决议」；正文先述会议名称、时间、通过方式，再分条列述决议事项；结语常用「会议号召」。
- **常见错误**：把未经会议表决的事项写成决议。

### 2. 决定
- **适用**：对重要事项作出决策部署、奖惩有关单位和人员、变更或撤销下级不适当决定。
- **要点**：标题「关于××的决定」；正文写决定缘由＋决定事项；奖惩性决定写明依据、事实与结论。
- **常见错误**：与决议混淆——决定可由领导机关直接作出，决议必须经会议表决。

### 3. 命令（令）
- **适用**：发布行政法规和规章、宣布实施重大强制性措施、批准授予晋升衔级、嘉奖有关单位和人员。
- **主体限制**：国家主席、人大及其常委会、国务院及其各部门、县级以上地方政府依法使用；党委系统一般不用命令。
- **要点**：标题「××机关令 第×号」；正文简短直接；落款为签发人职务＋签名章（不是机关署名）。**必须用 `--format command`**。
- **常见错误**：一般机关用命令发布事务性通知。

### 4. 公报
- **适用**：公开发布重大决定或重大事项，如统计公报、全会公报。
- **要点**：标题可不带发文字号；正文按事实或条目编排；面向社会公开，用语庄重平实。
- **常见错误**：与公告混淆——公报侧重「公布重大决定或事项的结果性信息」。

### 5. 公告
- **适用**：向国内外宣布重要事项或者法定事项，如选举结果、专利公告。
- **要点**：标题「××（机关）公告」或「关于××的公告」；无主送机关（面向国内外）；正文简明，结语「特此公告」。
- **常见错误**：滥用于机关内部或辖区内的一般事务周知（应用通告或通知）。

### 6. 通告
- **适用**：在一定范围内公布应当遵守或者周知的事项，如交通管制、拆迁通告。
- **要点**：无主送机关；正文写明缘由、事项（分条）、施行日期；结语「特此通告」。
- **常见错误**：与公告混淆——公告面向国内外，通告限于一定范围。

### 7. 意见
- **适用**：对重要问题提出见解和处理办法。上行（报上级）、下行（部署）、平行（供参考）均可。
- **要点**：标题「关于××的意见」；正文常为「总体要求＋分项意见＋落实要求」三段式；下行意见可要求下级贯彻执行。
- **常见错误**：意见与通知混用——提见解用意见，提执行要求用通知。

### 8. 通知
- **适用**：发布、传达要求下级机关执行和有关单位周知或者执行的事项；批转、转发公文。使用频率最高。
- **要点**：标题「关于××的通知」或「批转/转发××的通知」；批转/转发类通知正文极短（「现将××转发给你们，请遵照执行」）；事务性通知写明事项、要求、时限。
- **常见错误**：①把平行机关或不相隶属机关列为「主送机关」并要求其「贯彻执行」；②转发多层（「转发××关于转发××的通知的通知」）。

### 9. 通报
- **适用**：表彰先进、批评错误、传达重要精神或情况。
- **要点**：标题「关于××的通报」；正文「事实＋分析（定性）＋决定（表彰/处理）＋要求」四段式；批评性通报注意事实准确、用语分寸。
- **常见错误**：与通知混淆——通报重在「教育警示或表彰激励」，有叙事分析；通知重在「周知执行」。

### 速记口诀
> 决议决定是决策，命令嘉奖强制性；公报公告对外宣，通告辖内要周知；
> 意见三向提办法，通知批转执行快；通报表扬与批评；报告请示要分开；
> 报告不带请示事，请示必须事前行；批复只答请示件；议案专供人大审；
> 函给不相隶属，纪要记载会议事。

## 上行文专项：报告、请示、议案

### 10. 报告
- **适用**：向上级机关汇报工作、反映情况，回复上级机关的询问。
- **行文规则**：**不得夹带请示事项**（条例第十九条）。
- **要点**：标题「关于××的报告」或「××工作报告」；正文「工作情况＋问题＋下一步打算」；结语常用「特此报告」「以上报告，请审阅」。上行文版头需编排版签发人（与文号同行）。
- **常见错误**：①报告结尾夹带「请批准」「请批示」（应改请示）；②一事多报。

### 11. 请示
- **适用**：向上级机关请求指示、批准。**必须事前行文**，一文一事。
- **行文规则**：一文一事；不得抄送下级；主送一个上级机关（条例第十九条）。
- **要点**：标题「关于××的请示」；正文「请示缘由＋请示事项＋结语」；结语必须用请示用语：「妥否，请批示」「当否，请批复」「以上请示，请予审批」。
- **常见错误**：①先斩后奏（事项已实施才请示）；②一文多事；③结语用「请指示」（请示要批复，报告不要）。

### 12. 议案
- **适用**：各级人民政府按照法律程序向同级人民代表大会或其常务委员会提请审议事项。
- **主体限制**：**仅限政府**（含政府部门受政府委托），党委、群团不用议案。
- **要点**：标题「关于××的议案」；主送「××人民代表大会（常委会）」；正文「案由＋案据＋方案」；结语「请审议」。
- **常见错误**：非政府主体使用议案；与政协「提案」混淆。

## 平行与会议文种

### 13. 函
- **适用**：**不相隶属机关之间**商洽工作、询问和答复问题、请求批准和答复审批事项。
- **要点**：标题「××关于××的函」；平行文语气平和商洽，用「请予支持」「请予函复」；请求批准的函主送有审批权的不相隶属机关。**必须用 `--format letter`**（信函式版式：双线版头、首页无页码）。
- **常见错误**：①把函当命令使（对不相隶属机关用「必须」「务必」）；②该用函的用了请示（向不相隶属机关请求批准应发函，不发请示）。

### 14. 纪要
- **适用**：记载会议主要情况和议定事项。
- **要点**：标题「××会议纪要」，不写主送机关（周知范围用分送）；正文「会议概况（时间地点主持人参加人）＋议定事项＋工作要求」；纪要标志（标题）上边缘距版心上边缘 35mm，「出席」「请假」「列席」标签黑体、人员名单仿宋。**必须用 `--format minutes`**。
- **常见错误**：①把会议记录（流水账）当纪要；②纪要写入未议定或有分歧的事项。

### 15. 批复
- **适用**：答复下级机关请示事项。
- **要点**：标题「关于××的批复」或「××同意××的批复」；正文「引语（×字〔20××〕×号文收悉）＋答复意见＋结语」；结语「特此批复」。批复必须针对请示，一请示一批复。
- **常见错误**：①无对应请示的「主动批复」；②答复意见含糊（「同意」须写明同意什么）。

## 文种选择决策树

```
需要发公文
├── 是会议表决通过的重大决策 → 决议
├── 是领导机关决策部署/奖惩 → 决定
├── 是发布规章/强制措施/嘉奖且主体适格 → 命令（令）
├── 面向国内外宣布重要/法定事项 → 公告
├── 辖内公布应遵守/周知事项 → 通告
├── 公布重大决定或事项结果 → 公报
├── 对重要问题提见解和办法 → 意见
├── 发布/转发/周知/执行 → 通知
├── 表彰/批评/传达精神 → 通报
├── 向上级行文
│    ├── 汇报情况（不带请示）→ 报告
│    ├── 请求指示/批准 → 请示（事前、一文一事）
│    └── 政府向人大提请审议 → 议案
├── 向下级答复请示 → 批复
├── 不相隶属机关商洽/询问/请求批准 → 函
└── 记载会议议定事项 → 纪要
```

## 与生成器的配合

1. 按《文种速查表》确定 `--format` 参数（formal/command/letter/minutes）。
2. 上行文（报告/请示/议案）必须提供 `--signer`（签发人），生成器会与文号同行编排。
3. 函用信函版式，首页不显示页码。
4. 纪要用纪要版式，注意出席/列席名单的字体规则。
5. 通用版式细节（版心、字体、文号、附件、版记）见同目录 `gbt9704-2012-summary.md`。

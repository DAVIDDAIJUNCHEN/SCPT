## 0. 项目一句话

基于开源 New API（AGPL v3）二次开发并**已上线运行**的校内大模型 API 统一网关：**手机号实名注册、阿里云真实短信、10 个模型渠道（文本/图像/音频/ASR/语音全模态）、配额计费闭环、全链路运维监控**。部署于校内 VPS（10.255.12.210），供师生教学/科研使用。

## 1. 系统架构

```
┌────────────┐    HTTPS(内网)    ┌───────────────────────────────┐
│ 师生/管理员 │ ───────────────► │  VPS 10.255.12.210            │
└────────────┘                   │  ├─ Nginx (443 → 3000, 自签TLS) │
                                 │  ├─ gateway  (Go 单二进制,      │
                                 │  │   内含 React 前端<go:embed>) │
                                 │  ├─ PostgreSQL 16  (业务数据)   │
                                 │  └─ Redis 7       (缓存+限流)   │
                                 │  模型能力 ← AlloMax 集群(10渠道) │
                                 └───────────────┬───────────────┘
                                                 │
                    监控/告警: Prometheus+Grafana / 飞书 webhook / shell探针
```

**调用链**（一次模型请求）：
```
用户 → 前端(Playground/应用) → gateway(/v1 API) → 认证(token) → 计费(配额扣减)
     → 能力管控(RPM/TPM/并发) → 渠道分发 → AlloMax 模型 → 响应回传
```

## 3. 已实现功能（全量）

### 3.1 认证体系（P1 闭环 ✅）
- **手机号验证码注册/登录**：中国大陆手机号归一化（+86 容错），登录即注册
- **真实短信**：阿里云 Dysmsapi（直调 HTTP + RPC 签名，零 SDK 依赖）；mock 教学模式保留
- **三合一登录**：密码（手机号或用户名）/ 手机验证码 / 账号；忘记密码
- **验证码频控**：60s/号 + 60s/IP5次 + IP日20（Redis+内存兜底）
- **两步验证 2FA（TOTP）**：管理员绑定
- **协议/隐私页**：DeepSeek 化（服务协议 10 章 + 隐私 9 节，川邮智算中心主体）

### 3.2 计费商业闭环（P2 ✅）
- 10 模型渠道纳管；兑换码充值 + 新用户首充 10 元
- 多语言货币（¥/$/€...）、令牌可视化（RPM/TPM/并发）、消费洞察
- 模型定价对齐官网

### 3.3 能力管控（核心二开）
- **per-token RPM/TPM/并发/配额熔断**（`middleware/token-quota-control.go`）
- **ModelGuard 模型白名单**；渠道敏感字段防泄漏（channel_authz fail-closed）

### 3.4 管理与观测（P0/P3 完成后新增）
- **审计日志台账页**（操作审计 type=3 + 登录日志 type=7，admin 可查）
- **未知 IP 登录告警**（admin 非白名单 IP 登录 → 飞书，含用户名）
- **用量多维分析**（总览/按模型·用户·渠道/按天趋势）
- 健康探针 + 飞书告警、Prometheus+Grafana 监控、PG 定时备份、渠道自动测试

### 3.5 部署与运维（P3 ✅）
- Docker Compose 全容器化（gateway+PG+Redis）
- 一键部署脚本 `deploy/deploy.sh`；配置模板 `.env.example`

## 5. 部署指南（第三方可执行）

### 5.1 前置
- 一台 Ubuntu/CentOS VPS（建议 4C8G+），已装 Docker 与 docker compose v2

### 5.2 一键部署
```bash
# 获取代码
git clone git@github.com:DAVIDDAIJUNCHEN/SCPT.git
cd SCPT/api-gateway-platform

# 一键完成：构建镜像 → 生成/校验 .env → 启动 → 冒烟 → 初始化指引
chmod +x deploy/deploy.sh
./deploy.sh --all

# 后续运维
./deploy.sh --up        # 启动
./deploy.sh --smoke     # 冒烟
./deploy.sh --gen-secrets  # 生成随机密钥
```

### 5.3 关键配置（.env，见 deploy/.env.example）
| 变量 | 说明 |
|---|---|
| SESSION_SECRET / POSTGRES_PASSWORD / REDIS_PASSWORD | 必改强随机值 |
| SMS_PROVIDER | mock→aliyun（接真实短信）+ AK/SK/签名/模板 |
| ADMIN_IP_WHITELIST / FEISHU_WEBHOOK_URL | 未知 IP 告警 |
| DATA_DIR | 数据目录（默认 /data/allomax）|

### 5.4 初始化与管理
- 浏览器打开 `http://<IP>:3000` → 管理员初始化向导（或 `/api/setup`）
- 控制台 → 渠道/令牌/定价/用户/系统设置 配置
- 详细步骤见 `deploy/README.md`

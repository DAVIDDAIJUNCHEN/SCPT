> 本文档供**第三方部署方、学校决策、商务洽谈**对照使用。

## 1. 商用成熟度评估（产品经理 × 资深开发视角）

| 维度 | 评估 | 等级 |
|---|---|---|
| 功能完整性 | 认证/计费/管控/渠道/审计/用量全闭环 | ✅ 达标 |
| 安全 | 手机号实名、2FA、审计、未知IP告警、脱敏、权限 | ✅ 内网达标 |
| 可靠性 | PG 备份、监控、探针、channel 自测、git 版本化 | ✅ 有保障 |
| 部署可交付 | **新增 `deploy/deploy.sh` 一键部署 + 完整文档** | ✅ 已具备 |
| **对外域名/证书** | 现自签证书、Cloudflare 快速隧道 | 🔴 对外必须解决 |
| **在线支付** | 无（准备校方商户号） | 🔴 商业化缺环 |
| **License 合规** | AGPL v3，对外售卖需商业授权或开源本二开 | 🔴 交付前必须处理 |

### 结论
- **校内生产/教学/科研**：完全可用（当前定位成立）。
- **对外商用/卖给第三方**：功能与部署已就绪，但需补齐 **① 固定域名+证书 ② 在线支付 ③ License 合规** 三项，即可对外交付。

## 2. License 合规（AGPL v3）—— 务必阅读

本平台基于 **New API（AGPL v3）** 二次开发。

**AGPL v3 对你的三种使用方式的影响：**

| 使用方式 | AGPL v3 要求 |
|---|---|
| **校内自用（不对外服务）** | ✅ 无额外义务，正常使用 |
| **对外提供服务（网络上任何可用）** | ⚠️ 须向服务使用者提供**获取二开源代码**的途径（本仓库已满足） |
| **闭源商用 / 卖软件给第三方授权** | 🔴 须取得**上游 New API 的商业授权**（QuantumNous 官方付费），或与第三方在 AGPL 框架下协作 |

**建议**：
1. 明确你与第三方的合作模式（开源协作 vs 商业授权）；
2. 若走"卖软件/闭源"，先联系 QuantumNous 商谈商业授权，避免侵权风险；
3. 本仓库所有二开增量代码已列入 `docs/二开说明-川邮星语.md` §3，便于审计合规边界。

# 川邮·星语 AI 开放平台 — 向领导汇报（精简版）

> **汇报日期**：2026-09-08 ｜ 项目：四川邮电职业技术学院智算中心 · 校内大模型 API 统一网关
> 本页为给领导的高层汇报；完整工程细节见《完整开发文档（交接版）》。

## 一、项目一句话

已**上线运行**的校内 AI 大模型 API 统一网关：师生**手机号实名注册**、**真实短信验证码**、纳管**10 个模型渠道**（文本/图像/音频/语音全模态）、**配额计费闭环**、**全链路监控与安全告警**。服务我校教学与科研。

---

## 二、工程进展（已全部完成并上线）

| 阶段 | 内容 | 状态 |
|---|---|---|
| **P0 安全合规** | 管理员 2FA、操作审计台账、未知 IP 登录飞书告警、短信脱敏 | ✅ 完成 |
| **P1 认证闭环** | 手机号实名注册/登录、阿里云真实短信、三层验证码频控 | ✅ 完成 |
| **P2 计费闭环** | 10 渠道纳管、兑换码充值、令牌/配额/计费全链路 | ✅ 完成 |
| **P3 基础设施** | 容器化部署、Prometheus+Grafana 监控、PG 每日备份、健康探针 | ✅ 完成（除学校子域） |
| **业务增强** | 用量多维分析报表（按模型/用户/渠道/趋势） | ✅ 完成 |

**当前规模（实测）**：6 用户 / 4 令牌 / 10 渠道 / 数据库 11MB；VPS 16 核 / 62G / 1T。

---

## 三、给学校带来的价值

- **教学**：学生可基于平台做 API 二次开发、写应用、参与运营 → 讲透「AI 工程化」全链路（模型部署→网关纳管→应用）。
- **科研/课题**：可申报**软件著作权**（二开增量代码已清单化，1-2 月下证、成本低）；支撑 AI 教改、职教数字化转型课题。
- **建设成果**：智算中心「算力 → 平台 → 应用」完整展示，支撑校企合作、模型托管。

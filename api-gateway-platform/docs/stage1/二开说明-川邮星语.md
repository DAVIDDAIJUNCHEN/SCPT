# 川邮·星语 AI 开放平台 — 二次开发说明与技术总结

> 本文档面向**第三方使用方、学校/学院申报、评估人员**，说明本项目相对上游 New API 的全部二次开发内容、价值与合规性。
> 上游：QuantumNous/new-api（AGPL v3）｜ 本仓库：`api-gateway-platform/` 子目录

---

## 1. 项目定位

**"川邮·星语"AI 开放平台**：四川邮电职业技术学院智算中心建设的、面向教学/科研的大模型 API 统一网关。基于 New API 二次开发，新增**手机号实名认证、真实短信、能力管控、审计与告警、用量分析**等能力，支持文本/图像/音频/ASR/语音合成全模态模型的统一纳管、计费、鉴权与运维监控。

## 2. 二次开发计划（WHAT 全貌）

```
阶段1 基线：工程基线 + 容器化构建 + 手机号认证 + 能力管控 + 部署   ✅
阶段2 闭环：认证闭环(P1) + 计费商业闭环(P2)                       ✅
阶段3 加固：基础设施稳定化(P3) + 安全合规(P0) + 业务增强/体验(P1/P2)
阶段4 增强：在线支付(待校方商户) · 学校子域(待审批) · 精细计费等
```

## 3. 已实现功能（增量清单 + 核心文件）

| 模块 | 核心文件 | 说明 |
|---|---|---|
| 手机号注册/登录 | `controller/user_phone.go`、`common/phone_config.go` | +86 归一化、验证码登录即注册 |
| 真实短信 | `service/sms.go`、`model/sms_log.go`、`middleware/sms-verification-rate-limit.go` | 阿里云 Dysmsapi 真发、验证码脱敏、三层频控 |
| 两步验证 2FA | `controller/twofa.go` | TOTP 登录验证/设置/备份码/admin 管理 |
| per-token 能力管控 | `middleware/token-quota-control.go` | RPM/TPM/并发/配额熔断 + 模型白名单 |
| 未知IP登录告警 | `controller/admin_ip_alert.go` | admin 非白名单 IP 登录 → 飞书(含用户名) |
| 审计日志台账 | `web/src/features/audit-logs/` | 操作审计+登录日志可视化 |
| 用量多维分析 | `controller/usage_stats.go`、`web/src/features/usage-analysis/` | 总览/按模型·用户·渠道/趋势 |
| 品牌/协议/合规 | `web/src/features/legal/`、`web/src/features/about/` | DeepSeek 化协议/隐私 + AGPL 声明 |

## 5. 依赖

- **运行时**：Go(+gin/gorm)、PostgreSQL 16、Redis 7、前端 React+Bun
- **外部服务**：阿里云(Dysmsapi)、Cloudflare(隧道/监控)、飞书(告警)
- **上游**：New API(AGPL v3) 二开基线
- **部署**：Docker Compose 全容器化（见 `deploy/README.md`）

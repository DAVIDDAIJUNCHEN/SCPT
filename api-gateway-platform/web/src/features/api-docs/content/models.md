# 02-1 模型与价格

> 川邮·星语 API 开发者手册 · 信息核实日期 2026-09-23
> 计量单位：**百万 token**。token 是模型处理文本的最小单位，对中文而言 **1 token ≈ 1 个汉字**（口语化换算，便于估算；精确计数以接口 usage 字段返回为准）。

## 模型总览

平台模型按**分组**开放：注册即属 **default 分组**（4 款 LLM + 多模态功能系）；**vip 分组** 另含旗舰模型，见下文分组说明。

### default 分组（注册默认，4 款 LLM + 功能模型）

| 模型（即 API 的 model 取值） | 上下文长度 | 最大输出 | 输入价格<br>元/百万token | 输出价格<br>元/百万token | 定位 |
|---|---|---|---|---|---|
| **DeepSeek-V4.1-Flash** | **1M** | 32K | **1** | **4** | 默认推荐。速度快，1M 长上下文主力 |
| **Qwen3.8-Flash-Next** | **1M** | 32K | 0.8 | 2.7 | 中文优化，推理增强 |
| **GLM-5.3-Flash** | **1M** | 32K | 0.4<sup>†</sup> | 1.4<sup>†</sup> | 轻量快速，日常轻交互 |
| **DeepSeek-V4-Flash-0731** | 1M | 32K | 1 | 4 | DeepSeek-V4.1-Flash 的上一代版本 |
| bge-m3（Embedding） | 8K | — | 0.5 | — | 文本向量化，检索/RAG 用 |
| Qwen3-VL-30B-A3B-Instruct | 128K | 8K | 0.75 | 3 | 图像理解多模态，[样例](02-6-多模态视觉理解.md) |
| Qwen2-Audio-7B-Instruct / Qwen3-ASR-1.7B / cosyvoice-v3 | — | — | 1 | 1 | 语音理解/识别/合成 |

> 以上 4 款 LLM 价格为**现行配置实测值**【2026-09-23 从平台计费配置核对】，教室级场景折合：一次普通问答约 0.001~0.01 元。
> † GLM-5.3-Flash 当前为**半价优惠价**（原价 0.8 / 2.8 元），优惠期结束将恢复原价。

### vip 分组专享

| 模型 | 上下文 | 最大输出 | 输入价格 | 输出价格 | 说明 |
|---|---|---|---|---|---|
| **GLM-5.3**（旗舰） | 128K | 32K | 8 | 28 | 满血 744 亿参数，深度推理最强；稀缺整机资源，仅 vip 分组可见 |

> **分组说明**：注册账号默认属 **default 分组**；如需 **vip 分组**（旗舰模型 GLM-5.3），请联系**智算中心**开通。default 令牌调用 `GLM-5.3` 会返回 503「无可用渠道」——这是分组策略，不是故障【实测 2026-09-23】。

## 思考模式

- **DeepSeek-V4.1-Flash**：默认非思考模式（直接作答，快）【实测 2026-09-23】；需要深度推理建议选 Qwen3.8-Flash-Next（always-thinking，默认带思考过程）。
- **GLM-5.3**：思考模式，输出含 `reasoning_content` 字段（思考过程）与 `content`（答案）两段。
- 详细开关与样例见 [02-5 流式输出](02-5-流式输出.md)。

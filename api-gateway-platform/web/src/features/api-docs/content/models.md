# 02-1 模型与价格

> 川邮·星语 API 开发者手册 · 信息核实日期 2026-09-24
> 计量单位：**百万 token**。token 是模型处理文本的最小单位，对中文而言 **1 token ≈ 1 个汉字**（口语化换算，便于估算；精确计数以接口 usage 字段返回为准）。

## 模型总览

平台模型按**分组**开放：注册即属 **default 分组**（4 款 LLM + 多模态功能系）；**vip 分组** 另含旗舰模型，见下文分组说明。

### default 分组（注册默认，4 款 LLM + 功能模型）

| 模型（即 API 的 model 取值） | 上下文长度 | 最大输出 | 输入价<br>元/百万token | 缓存价<br>元/百万token | 输出价<br>元/百万token | 定位 |
|---|---|---|---|---|---|---|
| **DeepSeek-V4.1-Flash** | **1M** | 64K | **1** | **0.02** | **4** | 默认推荐。速度快，1M 长上下文主力。[长文调用](02-4-1M长上下文.md#调用样例) |
| **Qwen3.8-Flash-Next** | **1M** | 64K | 0.8 | 0.1 | 2.7 | 中文优化，推理增强。[思考/流式](02-5-流式输出.md#与思考模式的配合) |

> 以上价格为**现行配置实测值**【2026-09-24 从平台计费配置核对】，教室级场景折合：一次普通问答约 0.001~0.01 元。
> † GLM-5.3-Flash 当前为**半价优惠价**（原价 0.8 / 2.8 元），优惠期结束将恢复原价。
> **缓存价**：长文档/多轮对话中，平台自动对重复前缀（系统提示词、历史对话）做缓存，命中部分按缓存价计费（如 DS-V4.1 输入 1 元、缓存仅 0.02 元，长文档场景可省 98% 输入成本）。命中情况见接口 usage 字段的 `prompt_tokens_details.cached_tokens`。
> **「最大输出」口径**：即建议的 `max_tokens` 取值。传入更大的值（如实测 128K）服务端**不会报错**，仅自动截断到模型输出能力【实测 2026-09-24：四款 1M Flash 模型 `max_tokens=131072` 均正常返回】；GLM-5.3（vip）为部署侧硬上限。

### vip 分组专享

| 模型 | 上下文 | 最大输出 | 输入价 | 缓存价 | 输出价 | 说明 |
|---|---|---|---|---|---|---|
| **GLM-5.3**（旗舰） | 128K | 32K | 8 | 2 | 28 | 满血 744 亿参数，深度推理最强；稀缺整机资源，仅 vip 分组可见 |

> **分组说明**：注册账号默认属 **default 分组**；如需 **vip 分组**（旗舰模型 GLM-5.3），请联系**智算中心**开通。default 令牌调用 `GLM-5.3` 会返回 503「无可用渠道」——这是分组策略，不是故障【实测 2026-09-23】。

## 思考模式

- **DeepSeek-V4.1-Flash**：默认非思考模式（直接作答，快）【实测 2026-09-23】；需要深度推理建议选 Qwen3.8-Flash-Next（always-thinking，默认带思考过程）。
- **GLM-5.3**：思考模式，输出含 `reasoning_content` 字段（思考过程）与 `content`（答案）两段。
- 详细开关与样例见 [02-5 流式输出](02-5-流式输出.md)。

# 02-2 错误码

> 川邮·星语 API 开发者手册 · 信息核实日期 2026-09-23
> 调用星语 API 可能遇到以下错误。每条均给出**原因**与**解决方法**；标注【实测】的报文为平台真实返回。

## 400 — 格式错误

**原因**：请求体 JSON 格式错误（缺引号、缺括号、字段类型不对等）。
**解决方法**：按返回的 error message 提示修改请求体。用 `python -m json.tool` 或 `jq` 先本地校验一遍再发。

## 401 — 认证失败

**原因**：令牌错误、令牌已删除、或漏传 `Authorization: Bearer` 头。
**解决方法**：到 https://ai-platform.sptc.edu.cn 「令牌」页核对——确认令牌存在、未禁用、复制时无多余空格。

## 402 — 额度不足

**原因**：账号额度已耗尽。
**解决方法**：联系智算中心增加额度（校园平台无在线充值，按学期/按课申请）。

## 404 — 模型不存在

**原因**：`model` 参数写错（拼写错误，或使用了已退役的旧小写名如 `glm-5.3-flash`）。
**解决方法**：到 [02-1 模型与价格](02-1-模型与价格.md) 核对官方模型名，逐字符照抄。

## 422 — 参数错误

**原因**：请求体参数取值不合法（如 `max_tokens` 超上限、`temperature` 超范围）。
**解决方法**：按 error message 修改参数。注意各模型 `max_tokens` 上限见 02-1 各表「最大输出」列。

## 429 — 请求速率达到上限

**原因**：短时间内请求过于频繁，触发限流。
**解决方法**：等 30~60 秒后重试；代码里加指数退避（重试间隔 2s → 4s → 8s）。当前平台未设全局令牌 RPM 限制【实测 2026-09-23】，个人正常使用几乎不会触发；若频繁触发请联系智算中心核查。

## 500 — 服务器故障

**原因**：平台内部故障。
**解决方法**：等待 1~2 分钟后重试；若持续出现，联系智算中心（附上 request id，报文里有，可精确定位）。

## 502 — 网关错误

**原因**：**校园自签证书校验失败**（星语平台最高频报错）【实测】。您的工具没挂证书，TLS 握手就被拦下，请求根本没到模型。
**解决方法**：按 [02-0 第二步](02-0-首次调用API.md#第二步处理校园自签证书星语特有最重要的一步) 挂证书——curl 加 `-k`，Python 加 `verify=False`，Node 设 `NODE_EXTRA_CA_CERTS`。WorkBuddy 用户见 01 手册 ca.pem 流程。

## 503 — 服务器繁忙（两种情况，先看报文内容）

**情况 A：排队满**
**原因**：模型并发队列已满（如全班同学同时提交长文），平台**主动拒绝新请求**以保护在跑任务——这是保护机制，不是宕机，不会丢失已在处理的请求。
**解决方法**：等 1~2 分钟后重试。实测撤压后 15 秒恢复【压测验收 2026-09-23】。

**情况 B：无可用渠道**
**原因**：调用了 vip 专享模型但令牌属于 default 分组（如普通令牌调用 `GLM-5.3`）。报文样例【实测 2026-09-23】：
```json
{"error":{"code":"model_not_found","message":"分组 default 下模型 GLM-5.3 无可用渠道（distributor）","type":"new_api_error"}}
```
**解决方法**：换用 default 分组可用的模型（见 02-1），或联系智算中心开通 vip 分组。

## 快速排查顺序（新手推荐）

```
报错 → 是 SSL/证书字样或 502？
     ├─ 是 → 挂证书（02-0 第二步），90% 的报错到这步就解决
     └─ 否 → 看错误码：
          401 → 核对令牌
          404 → 核对模型名
          503 → 看报文：queue full 等等再试 / model_not_found 换模型
          其他 → 带上 request id 联系智算中心
```

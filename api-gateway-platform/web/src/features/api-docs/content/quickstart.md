## 一、两个入口，记住就行

| 想做什么 | 打开这个网址 |
|---|---|
| **直接和 AI 聊天**（最常用） | https://ai-chat.sptc.edu.cn |
| **管理账号 / 创建 API 令牌** | https://ai-platform.sptc.edu.cn |

两个网址用**同一个账号**（注册手机号 + 密码/验证码），登录一次即可互通。

> 📱 **手机端说明**：手机浏览器可以直接打开上述网址使用，首次证书信任操作与电脑相同（见下）。手机专版教程暂未提供，如遇体验问题请向智算中心反馈，视反馈情况补充。

## 二、第一次使用：3 步搞定

**第 1 步 · 处理"连接不是私密连接"提示（只需一次）**

校园网内打开网址，浏览器可能提示"您的连接不是私密连接"——这是因为平台使用学校自签发的安全证书（数据不出校）。点：

- **Chrome**：高级 → 继续前往 ai-chat.sptc.edu.cn（不安全）
- **Edge**：详细信息 → 转到此网页（不推荐）

每台设备、每个浏览器**只需操作一次**。

**第 2 步 · 注册账号**

打开 https://ai-platform.sptc.edu.cn → 注册 → 输入手机号 → 填收到的短信验证码 → 设置密码 → 完成。

**第 3 步 · 开始聊天**

打开 https://ai-chat.sptc.edu.cn → 登录 → 页面顶部选择模型 → 输入框打字发送。就这么简单。

## 三、模型怎么选（新手版）

| 你想做的事 | 选这个模型 |
|---|---|
| 日常问答、写作、翻译（默认） | DeepSeek-V4.1-Flash |
| 更强的推理、代码、深度分析 | GLM-5.3（需 vip 分组，联系智算中心开通；日常推理需求 Qwen3.8-Flash-Next 也可胜任） |
| 看图说话（拍照提问、读图表） | Qwen3-VL |
| 语音相关功能 | 按平台功能入口选择 |

> 想一次读完超长文档（最长约 100 万字）？选 DeepSeek-V4.1-Flash 后上传文档即可——超长文档首次回复需要几分钟，属正常现象。

## 四、遇到问题？

| 现象 | 原因 | 怎么办 |
|---|---|---|
| "连接不是私密连接" | 首次使用未信任证书 | 见第二步第 1 步 |
| 提示"稍后再试"/排队 | 高峰期使用人数多 | 等 1~2 分钟重试，**不会丢数据** |
| 某模型提示不可用 | 部分高性能模型限特定用户组 | 换 DeepSeek-V4.1-Flash |
| 打不开网页 | 不在校园网 | 校外需通过学校 VPN 接入 |

**反馈渠道**：信息工程学院（智算中心）。

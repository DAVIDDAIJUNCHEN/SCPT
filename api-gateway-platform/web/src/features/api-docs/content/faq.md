## 二、计费怎么算（三句话版）

1. **费用 = 输入字数 × 输入价 + 输出字数 × 输出价**（相同前缀命中缓存的部分按缓存价）。
2. **没有充值**：校园额度制，额度在平台控制台（ai-platform.sptc.edu.cn）查看。
3. **体感成本**：一次普通问答（约 500 字提问 + 300 字回答）≈ **0.002 元**；一次百万字长文档分析 ≈ 1~2 元。

**课堂场景估算**【理论折算】：一个班 50 人 × 每人 20 次问答 ≈ 2 元；一门课一学期整班使用 ≈ 数十元——教学成本可忽略。

## 三、常见问题（FAQ）

### 使用类

| 问题 | 答案 |
|---|---|
| 怎么开始用？ | 校园网打开 https://ai-platform.sptc.edu.cn 手机号注册；网页聊天直接用 https://ai-chat.sptc.edu.cn |
| 模型怎么选？ | 日常问答选 DeepSeek-V4.1-Flash（默认）；深度推理/代码选 GLM-5.3（需 vip）；看图选 Qwen3-VL；具体见[模型速查表](#一模型速查总表) |
| 100 万字长文真能用吗？要等多久？ | 能，已实测 97.4 万字通过【实测】；8 万字约 10 秒返回，百万字约 6.5 分钟开始作答，属正常现象 |
| 为什么 GLM-5.3 不支持 100 万字？ | 模型架构（DSA 注意力）显存开销大，是行业共性天花板，非平台缺陷；长文需求用 3 款 1M 模型即可 |
| 提示"稍后再试"/排队？ | 高峰期并发已满，等 1~2 分钟重试即可，**不会丢数据、不会崩溃**【压测验收】 |
| 人太多平台会崩吗？ | **不会**——超载自动排队或礼貌拒绝，撤压 15 秒恢复基线；200 路并发压测零宕机【压测验收】 |
| 数据安全吗？ | 全链路校内闭环，对话内容不经过任何外部厂商 |

### 开发者类

| 问题 | 答案 |
|---|---|
| 报 502 怎么办？ | 九成是**自签证书没挂**（curl 加 `-k`、Python 加 `verify=False`），详见[02-2 错误码](T8-02-2-错误码.md) |
| 429 和 503 有什么区别？ | 429 = 请求频率过快，慢一点；503 = 排队满或无可用渠道，等 1~2 分钟。都带指数退避重试即可 |
| 调 GLM-5.3 返回 503？ | default 分组令牌无 vip 权限（`model_not_found`），联系智算中心开通 vip 分组，不是故障 |
| 返回里多一段"思考过程"？ | Qwen3.8-Flash-Next / GLM-5.3 默认带思考模式，思考过程在 `reasoning_content` 字段，答案在 `content`，代码里只取后者即可 |
| 长文档多轮追问太贵？ | 相同前缀自动命中缓存按缓存价计费（如 DS-V4.1-Flash 缓存价仅 0.02），把长文档放在消息开头即可享受 |
| 校外能用吗？ | 当前面向校园网；校外请先接入学校 VPN |
